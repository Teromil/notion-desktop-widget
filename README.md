# Notion-виджет для рабочего стола Windows

Небольшое окно на рабочем столе в стиле Notion: задачи на сегодня из базы Notion, календарь,
события Google Календаря, ИИ-помощник, плеер Spotify, нагрузка компьютера и лимиты Claude.
Светлая и тёмная тема переключаются вслед за Windows.

## Возможности

- **Задачи из Notion** на выбранный день, со временем и цветными тегами. Чекбокс сразу отмечает задачу
  выполненной в Notion, клик по названию открывает её в Notion.
- **Просроченные задачи** наверху красным; задачи, время которых сегодня уже прошло, тоже краснеют.
- **Быстрое добавление**: пишешь «созвон завтра 15:00», «отчёт в пятницу», «лекция 12.11 в 10» и жмёшь Enter.
- **Фильтр по тегам**, **ближайшие дни** недели и **календарь на месяц** с точками на днях, где есть задачи.
- **Напоминания** уведомлением Windows за N минут до задачи, один раз на задачу.
- **Google Календарь**: события из секретной ссылки iCal, включая повторяющиеся.
- **ИИ-помощник** (кнопка ✦): Gemini (есть бесплатный тариф) или Claude. Видит твои задачи на неделю.
- **Spotify**: обложка, название, ⏮ ⏯ ⏭, перемотка и громкость самого Spotify. Аккаунт разработчика и Premium не нужны.
- **Нагрузка ЦП / ГП / ОЗУ** — те же цифры, что в диспетчере задач.
- **Лимиты Claude** (5 часов и неделя) и кнопка, открывающая приложение Claude.
- **Размер окна**: тянешь за уголок, и виджет показывает больше или меньше; от 560 px в ширину — две колонки.
- **Мини-режим**, «поверх всех окон», скрытие по Ctrl+Alt+N, иконка в трее, автозапуск с Windows.

## Установка

Нужны Windows 10/11 и Python 3.11+.

```powershell
git clone <ссылка на этот репозиторий> "Notion Widget"
cd "Notion Widget"
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy config.example.json config.json
```

Запуск — двойной клик по `run_widget.bat`. Без `config.json` виджет открывается в демо-режиме с тестовыми задачами.
Автозапуск включается в меню иконки «N» в трее: «Автозапуск с Windows».

## Подключение Notion

1. Открой https://www.notion.so/profile/integrations → **New connection** (Internal) и скопируй токен
   (начинается с `ntn_`). В Capabilities включи Read, Update и Insert content.
2. В Notion открой страницу, внутри которой лежит база задач → `•••` → **Connections** → выбери своё подключение.
3. В виджете нажми **⚙** и вставь токен и ссылку на базу. Укажи названия свойств твоей базы:
   дата (например, `Date`), статус (`Status`) и его значения «готово» и «не начато» (`Done` / `Not started`), теги (`Tags`).
   Свойство статуса может быть Checkbox, Status или Select.
4. **Сохранить и перезапустить**.

## Настройки (кнопка ⚙)

| Раздел | Что настраивается |
|---|---|
| Notion | токен, база, названия свойств |
| ИИ-помощник | Gemini или Claude, ключи и модели |
| Google Календарь | секретные ссылки iCal, по одной в строке |
| Виджет | тема, горячая клавиша, «напомнить за N мин», частота обновления, Spotify, нагрузка, лимиты Claude |

Сохранённые ключи в форме не показываются: пустое поле значит «оставить как есть».
Всё хранится в `config.json` рядом с виджетом. Этот файл не попадает в git.

**Ключ Gemini** бесплатно: https://aistudio.google.com → Get API key.
**Ключ Claude**: https://platform.claude.com → API keys (оплачивается отдельно от подписки Claude).
**Google Календарь**: настройки календаря → «Секретный адрес в формате iCal».

## Как пользоваться

| Действие | Как |
|---|---|
| Отметить задачу выполненной | чекбокс слева от задачи |
| Открыть задачу в Notion | клик по названию |
| Добавить задачу | поле «Новая задача», текст и Enter |
| Задачи другого дня | клик по дню в календаре или в «ближайших днях» |
| Перетащить окно | за шапку |
| Мини-режим (день, часы, ближайшая задача) | двойной клик по шапке |
| Поверх всех окон | 📌 (синий — включено) |
| Скрыть / показать | **—** или **Ctrl+Alt+N**, или клик по иконке «N» в трее |
| Изменить размер | тянуть за правый нижний уголок; двойной клик по уголку — обычный размер |
| Перемотать трек | полоса под названием трека |
| Открыть Claude | оранжевая иконка под нагрузкой |
| Обновить лимиты Claude | клик по полоскам лимитов |
| Закрыть совсем | «Выход» в меню трея |

Когда окно маленькое, второстепенное прячется по порядку: плеер → календарь → неделя → нагрузка →
лимиты Claude → теги → просроченные → поле ввода. Список задач остаётся всегда и прокручивается.

## Лимиты Claude

Работают на подписках Pro, Max и Ultra и нужен терминальный Claude Code:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Один раз запусти `claude` и войди в аккаунт. Дальше виджет сам обновляет лимиты после запуска компьютера
и раз в час, пока открыт Claude: делает крошечный фоновый запрос к модели Haiku (`claude -p`),
в ответе которого Claude Code сообщает остаток лимитов. Такие запросы не сохраняются в историю сессий.

Дополнительно лимиты может записывать строка состояния Claude Code (`claude_statusline.py`).
Для этого в `~/.claude/settings.json`:

```json
{
  "statusLine": {
    "type": "command",
    "command": "& 'C:/путь/к/виджету/.venv/Scripts/python.exe' 'C:/путь/к/виджету/claude_statusline.py'"
  }
}
```

`&` в начале нужен, когда Claude Code запускает команды через PowerShell (если Git Bash не установлен).
С установленным Git Bash используй
`powershell -NoProfile -Command "& 'C:/путь/.venv/Scripts/python.exe' 'C:/путь/claude_statusline.py'"`.

## Как устроено

Интерфейс — HTML/CSS/JS в окне `pywebview` (встроенный в Windows движок Edge WebView2).
Логика — Python.

| Файл | Что внутри |
|---|---|
| `notion_widget.py` | окно, мост Python ↔ страница, фоновые задачи, настройки |
| `ui/index.html`, `ui/style.css`, `ui/app.js` | внешний вид и поведение — правь здесь, чтобы менять дизайн |
| `notion_api.py` | Notion API: задачи, отметка «готово», создание |
| `ical_feed.py` | Google Календарь (iCal), повторяющиеся события |
| `quick_add.py` | разбор «созвон завтра 15:00» |
| `gemini_chat.py`, `claude_chat.py` | ИИ-помощник |
| `spotify.py` | Spotify через медиа-API Windows и микшер громкости |
| `sysstats.py` | нагрузка ЦП / ГП / ОЗУ из счётчиков Windows |
| `claude_usage.py`, `claude_statusline.py` | лимиты Claude |
| `notifier.py`, `hotkey.py`, `tray.py` | уведомления, горячая клавиша, трей и автозапуск |
| `legacy_tk_widget.py` | первая версия на tkinter (запасная) |

Файлы, которые виджет создаёт сам и которые не попадают в git: `config.json` (настройки и ключи),
`state.json` (позиция и вид окна), `notified.json` (показанные напоминания), `claude_limits.json`.
